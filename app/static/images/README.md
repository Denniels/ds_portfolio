# Directorio de Imágenes

Este directorio contiene las imágenes utilizadas en el portafolio de Data Science.

## Estructura:

- `logos/` - Logos de instituciones y organizaciones
- `charts/` - Gráficos e imágenes de apoyo para visualizaciones
- `backgrounds/` - Imágenes de fondo para secciones
- `icons/` - Iconos personalizados

## Notas:

- Todas las imágenes deben estar optimizadas para web
- Formatos preferidos: PNG para transparencias, JPG para fotografías, SVG para iconos
- Tamaño máximo recomendado: 1MB por imagen
